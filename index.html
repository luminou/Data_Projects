Data projects from the lab

Before moving into tech art, I was a biology researcher working with a lot of data. I developed these two Python tools to help me manage it: one turns a 27,000-row screening database into an interactive dashboard, the other automates the reporting of dozens of lab runs. Each page explains the problem, the code and the result, and lets you try the tool.

Molecule ExplorerInteractive dashboard · 2019–2020

A Bokeh web app that lets biologists filter a chemical screening database by molecule, receptor, mode and serum, and read dose–response curves, bars and tables in a few clicks. The page lets you use it in the browser on the real example data, with an overview heatmap and Hill-curve fitting.

Screen GrabBatch reporting automation · 2023

A script that opens every run workbook of a validation study, extracts the identity, controls, luminescence and viability values from fixed cells, and exports one report-ready table image per chemical. The page shows, cell by cell, how a workbook becomes an image.
